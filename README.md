# Jogo do Dino 🦖

Jogo simples inspirado no famoso jogo do Dino do navegador.

## Funcionalidades

* Dino que pula com a tecla `Espaço`
* Obstáculo de cacto
* Detecção de colisão
* Mensagem de derrota

## Como jogar

Abra o arquivo `index.html` no navegador.

Pressione:

```text
Espaço → Pular
```

Evite bater no cacto! 🌵

## Tecnologias

* HTML
* CSS
* JavaScript
